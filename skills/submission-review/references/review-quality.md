# Formative review quality

- Compare the submission with the actual prompt and criteria supplied.
- Prioritize task completion, organization, clarity, grammar, vocabulary, collocations, and register.
- Provide a complete corrected version when requested or useful and editable text is available. Otherwise, correct priority patterns selectively and leave room for learner self-correction; preserve the learner's ideas and voice.
- Answer in two labeled parts, in this order:
  1. **Feedback for the learner** — short, in the requested language, with at most three priorities. Each priority shows a before→after example taken from the learner's own submission and closes with a concrete action for the next submission. The "after" rewrites only the learner's own words, adds no new content, and is itself correct; check every word you keep, including the one you are correcting.
  2. **Notes for the teacher** — the full analysis: strengths and patterns across the submission, alignment with the supplied criteria, what could not be evaluated, and a suggested grade only when an explicit scale and criteria are both available.
- For line-by-line feedback, attach every comment to an exact passage in the source or correction. Rewrite a comment if its anchor is unclear.
- A grade alone does not replace an explanation. Never invent a grade when the scale or criteria are missing.
- For audio without a transcript, do not invent one or provide a full rewrite; give feedback on observable features supplied.
